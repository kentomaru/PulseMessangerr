# Pulse — заметки по звонкам и хранению файлов

## Звонки: что было и как исправлено

### 1. Звук не слышно, пока не включишь видео/демонстрацию
Причина была не в сети: воспроизведение чужого звука отдавалось на откуп
`<audio autoPlay>` без явного `.play()`. К моменту, когда приходил первый
аудиопоток, браузер (особенно при отсутствии жеста «рядом») молча блокировал
автоплей. Включение демки случайно давало новый цикл перерисовки — и автоплей
проходил.

Фикс: звук играет через обычный `<audio>` с явным `.play()` и повтором по
первому клику пользователя, контейнеры звука не прячутся `display:none`.

### 2. Чёрная плитка демки у собеседника после выключения
`stopScreenShare` подставлял на место демки `replaceTrack(null)`/выключенную
камеру — у получателя дорожка оставалась «живой» без кадров.

Фикс: если рабочей камеры нет — видеосендер **удаляется полностью**
(`pc.removeTrack` + пересогласование), дорожка у собеседника корректно
завершается, `ontrack` слушает событие `ended` и сразу вычищает дорожку из
локального потока. Плитки рендерятся только при живой И не-мьюченной дорожке.

### 3. «Участников: 2, Соединений: 0»
У запросов не было таймаута: один зависший запрос навсегда блокировал
синхронизацию соединений (`syncingRef`).

Фикс: таймаут 8 с на все API-запросы (`AbortController`) + самоснятие
блокировки синхронизации через 12 с + сторожевой цикл, который сам
пересоздаёт потерянные соединения и по статистике `getStats()` лечит тишину
(свежий захват микрофона + ICE-рестарт).

### 4. Диагностика в окне звонка
Кнопка с пульсом: по каждому участнику видно статус соединения и счётчики
байтов звука ↑/↓. Плюс полоска уровня собственного микрофона.

## Хранение файлов: Backblaze B2
Основное хранилище — приватный bucket B2 (доступ только через подписанные
ссылки на 1 час). Диск контейнера — горячий кэш, копия в БД — запасной путь,
если B2 не настроен/недоступен. `GET /api/files/[name]` редиректит (302) на
подписанную ссылку, если файла нет ни на диске, ни в БД; перемотку
аудио/видео (Range) B2 обрабатывает сам.

Переменные (см. `.env.example`): `B2_KEY_ID`, `B2_APPLICATION_KEY`,
`B2_BUCKET`, `B2_REGION`. Bucket должен быть **приватным**.

## Безопасность
- Логин: 8 попыток на (IP+логин) за 5 минут, дальше 429 (`src/lib/rate-limit.ts`).
- Регистрация: пароль минимум 8 символов.
- Пароли: scrypt + соль + timingSafeEqual; сессии — httpOnly/sameSite cookie.
- Загрузки: расширение определяется по MIME-белому списку, не по имени от клиента.
